LumaAI – Agente Inteligente para Gestión de Consultorios Médicos
Descripción del proyecto

LumaAI es un agente inteligente diseñado para apoyar la administración básica de consultorios médicos y la organización de citas. El sistema permite gestionar recordatorios, organizar agendas, realizar seguimiento administrativo de pacientes y automatizar mensajes relacionados con citas médicas.

El agente busca optimizar el tiempo del personal médico y mejorar la comunicación entre doctores, secretarias y pacientes, mediante funciones automáticas y una agenda inteligente.

Objetivo general

Desarrollar un agente inteligente capaz de administrar y organizar citas médicas, automatizar recordatorios y facilitar la gestión básica de pacientes en consultorios médicos.

Objetivos específicos

1.Organizar agendas médicas y horarios de atención.
2.Automatizar recordatorios de citas y controles médicos.
3.Gestionar información básica de pacientes de forma organizada.
4.Generar mensajes automáticos para confirmaciones y reprogramaciones.
5.Facilitar el seguimiento administrativo de consultas y controles.

Metodología

El proyecto se desarrollará mediante una metodología ágil, permitiendo realizar mejoras constantes durante el proceso.

Etapas del desarrollo

1.Recolección de requerimientos.
2.iseño del agente inteligente.
3.Desarrollo de funcionalidades.
4.Pruebas y validación.
5.Implementación final.

Responsabilidades

Desarrollador
Diseñar y programar el agente inteligente.
Configurar recordatorios y automatizaciones.
Realizar pruebas del sistema.
Corregir errores encontrados.

Usuario/Consultorio

Proporcionar la información necesaria de citas y horarios.
Verificar el correcto funcionamiento del sistema.
Administrar los datos ingresados en la agenda.

Test del sistema

Prueba 1: Registro de citas
Resultado esperado: El sistema guarda correctamente la información del paciente y la cita.

Prueba 2: Envío de recordatorios
Resultado esperado: El agente envía alertas antes de la cita programada.

Prueba 3: Cambio de estado de cita
Resultado esperado: La cita puede cambiar entre pendiente, confirmada o cancelada.

Prueba 4: Generación de mensajes automáticos
Resultado esperado: El sistema genera mensajes de confirmación y reprogramación correctamente.
